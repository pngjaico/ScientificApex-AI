# AI-Style Marker Reference

Use this reference when text sounds model-generated, generic, over-polished, or detector-oriented.

## Common Markers

- Empty transitions: "vale ressaltar", "e importante destacar", "alem disso" repeated, "no contexto de", "a luz de", "em suma".
- Inflated adjectives: "crucial", "robusto", "abrangente", "notavel", "transformador", "inovador", "pivotal", "comprehensive".
- Generic insight language: "insights valiosos", "panorama abrangente", "contribui para a literatura", "complexa interacao", "intricado".
- Symmetrical filler: three-part lists of abstract nouns that do not map to methods or results.
- Overclaiming: "prova causal", "definitivo", "essencial", "sem precedentes", "mudanca de paradigma" without design support.
- Template endings: "mais estudos sao necessarios" without naming what study, endpoint, population, comparator, or uncertainty remains.

## Safer Rewrites

- Replace "fornece insights valiosos" with the actual finding.
- Replace "abordagem robusta" with the design, sample, sensitivity analysis, or validation step.
- Replace "e importante destacar que" with the fact itself, or remove it.
- Replace "no contexto de" with the actual setting or analysis.
- Replace "mais estudos sao necessarios" with the specific validation gap.

## Ethics

This skill does not bypass AI detectors. It improves scientific authorship and removes generic model style while preserving evidence. If AI assistance must be disclosed under a journal, institution, or author policy, keep the disclosure.
