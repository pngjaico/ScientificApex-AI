# Read me — on-demand scientific catalog

This package records five public repositories pinned by SHA for manual consultation. It does not install or activate skills.

- [Source audit](auditoria_das_fontes.md): counts, licenses, inspected frontmatter, risks, and limits.
- [On-demand catalog](catalogo_sob_demanda.md): PT-BR/EN intent gateway and minimum local set.
- [`../manifesto_das_fontes.json`](../manifesto_das_fontes.json): refs, SHAs, observed dates, licenses, counts, and submodules.
- [`../inventario_de_habilidades.json`](../inventario_de_habilidades.json): names and paths; `tree_only` means the content was not reviewed.

The comparison uses the historical local baseline of 267 skills. The gateway integrated afterward brought the coordinator-reported local catalog to 268; that later addition is not included in the audit percentages. The governance project remains in `bootstrap`.

Shallow clones are under `../`. The first K-Dense checkout was interrupted; `kdense_reference` is a duplicate ref at the same SHA. Do not interpret clone presence as a clean checkout, benchmark, or scientific validation.
