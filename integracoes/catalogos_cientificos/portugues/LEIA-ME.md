# Leia-me — catálogo científico sob demanda

Este pacote registra cinco repositórios públicos fixados por SHA para consulta manual. Não instala nem ativa skills.

- [Auditoria das fontes](auditoria_das_fontes.md): contagens, licenças, frontmatters inspecionados, riscos e limites.
- [Catálogo sob demanda](catalogo_sob_demanda.md): gateway PT-BR/EN por intenção e conjunto local mínimo.
- [`../manifesto_das_fontes.json`](../manifesto_das_fontes.json): refs, SHAs, datas, licenças, contagens e submódulos.
- [`../inventario_de_habilidades.json`](../inventario_de_habilidades.json): nomes e caminhos; `tree_only` significa que o conteúdo não foi revisado.

O comparador usa baseline histórico local de 267 skills. O gateway integrado depois elevou o catálogo local informado para 268; essa adição posterior não foi incluída nos percentuais da auditoria. O projeto de governança permanece `bootstrap`.

Os clones rasos ficam em `../`. O primeiro checkout K-Dense foi interrompido; `kdense_reference` é uma referência duplicada no mesmo SHA. Não confunda presença do clone com checkout limpo, benchmark ou validação científica.
