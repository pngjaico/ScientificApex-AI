# Audit of five external scientific skill catalogs

**Source snapshot:** 2026-11-02. **Project:** `article-machine-governance-2026`, still in `bootstrap`. This package records an inventory; it does not advance the project mode or change central routing.

## Method and denominators

`git ls-remote --symref` confirmed `HEAD` and `main` for each official URL; shallow/partial Git clones pin those commits. Counts below come from the Git trees and match the exact `SKILL.md` basename. Frontmatter was read only for the candidates named below. All other names and paths are marked `tree_only` in [`inventario_de_habilidades.json`](../inventario_de_habilidades.json): their presence in a tree does not mean their content or behavior was reviewed. No upstream hook, script, installer, lifecycle, `npx`, or other code was executed.

The original comparison used a **baseline of 267** files at `skills/*/SKILL.md`. That is historical: the local gateway was integrated afterward, bringing the coordinator-reported local catalog to **268**. The percentages below remain comparable to the 267 baseline and were not recalculated against the newer gateway. Overlap counts use exact directory-slug matches only; they do not establish equivalent purpose, behavior, or quality.

## Frontmatter and risks observed

- **K-Dense:** reviewed `statistical-analysis`, `clinical-reports`, `scientific-writing`, `pytorch-lightning`, `uncertainty-and-units`, `analytical-method-validation`, and `pkpd-modeling`. [`uncertainty-and-units`](https://github.com/K-Dense-AI/scientific-agent-skills/blob/a25cf9ec00e2745d03f8704acf6f6919694ccd9a/skills/uncertainty-and-units/SKILL.md) and [`analytical-method-validation`](https://github.com/K-Dense-AI/scientific-agent-skills/blob/a25cf9ec00e2745d03f8704acf6f6919694ccd9a/skills/analytical-method-validation/SKILL.md) have slugs absent from the local baseline and describe local tools that need no network. They are benchmark candidates, not approved additions. `pytorch-lightning` declares `Read Write Edit Bash`, optional external logging, and GPU/cloud guidance that was not executed.
- **DenDen:** the inspected `statistical-analysis` skill shares a slug and stated purpose with K-Dense; this does not prove the 75 skills are identical. Its README mentions BYOK and optional Modal; no service was connected. Its April snapshot predates the K-Dense HEAD observed in November.
- **Orchestra:** [`ml-paper-writing`](https://github.com/Orchestra-Research/AI-research-SKILLs/blob/773a52944ba4747a18bd4ae9ade53fff041adcbc/20-ml-paper-writing/ml-paper-writing/SKILL.md) declares dependencies on `semanticscholar`, `arxiv`, `habanero`, and `requests`. `autoresearch` mentions Claude Code `/loop`, OpenClaw heartbeat, result/checkpoint files, and cloud compute; `rigor-reviewer` proposes review scoring without an independently observed benchmark. These are author instructions and claims, not validation.
- **Imbad:** inspected frontmatter for [`academic-paper`](https://github.com/Imbad0202/academic-research-skills/blob/2e02041a3b821a160d98c9398f173c484ac759a8/academic-paper/SKILL.md), [`academic-paper-reviewer`](https://github.com/Imbad0202/academic-research-skills/blob/2e02041a3b821a160d98c9398f173c484ac759a8/academic-paper-reviewer/SKILL.md), and [`academic-pipeline`](https://github.com/Imbad0202/academic-research-skills/blob/2e02041a3b821a160d98c9398f173c484ac759a8/academic-pipeline/SKILL.md). ## Recommendation

Do not activate any catalog wholesale. Keep all five refs available by SHA. Three candidates for isolated evaluation are K-Dense `analytical-method-validation` (if there is a lab use case), K-Dense `uncertainty-and-units` (after code review and independent numerical tests), and Orchestra `ml-paper-writing` (only for an ML/AI paper with a stated venue). This is not approval to integrate them.

For medicine and clinical reporting, K-Dense `clinical-reports` and `clinical-decision-support` already have slugs in the local baseline. For systematic review/meta-analysis, the local stack already has dedicated routes and no new external increment was confirmed. Orchestra is specific to ML papers; Imbad is a pipeline-design reference, not a copy candidate. Without a concrete use case, the recommendation is **zero new skills**.

## Limits

- These entries remain unread: 170 K-Dense, 74 DenDen, 95 Orchestra, and 2 Imbad `SKILL.md` files. This is a tree inventory with spot checks, not a complete security or portability review.
- Slug equality does not detect semantic overlap; trigger comparison is also limited to inspected frontmatter. There was no benchmark, clinical test, methodological validation, or independent evaluation.
- Clones do not materialize the full catalogs. The first K-Dense checkout was interrupted during materialization and left a partial working copy; a second no-checkout ref uses the same SHA. Both remain under `integracoes/catalogos_cientificos/`.
- The project remains in `bootstrap`; this package approves no gate or readiness claim.
